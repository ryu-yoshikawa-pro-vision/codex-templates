# Support

## Supported

- Template usage and setup questions
- Documentation clarification
- Validation and verification issues
- Safe workflow questions

## Best effort

- Local shell differences (Bash vs PowerShell)
- Codex provider configuration
- Unofficial or experimental models
- Non-standard environments

## Not supported

- Bypassing approval or sandbox mechanisms
- Production destructive automation
- Billing, quota, or account troubleshooting
- Issues unrelated to this template

## Code of conduct reports

Do not include harassment reports, personal information, or sensitive conduct details in public issues or discussions.

If a private reporting channel is available, use it. If no private channel is currently listed, open a minimal public issue asking maintainers to provide a private reporting channel, without sensitive details.

## Security issues

Security-related concerns should be reported through the process described in [SECURITY.md](SECURITY.md), not through support channels.
