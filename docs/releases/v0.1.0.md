# v0.1.0 release notes draft

## Summary

Initial OSS-ready release of `codex-templates`.

This release provides a safety-first repository template for Codex / coding-agent workflows, including planning, review, validation, controlled execution modes, and run artifact conventions.

## Highlights

- Consumer-ready README and quickstart.
- Apache-2.0 license.
- Contribution, security, support, and code of conduct documents.
- Issue and pull request templates.
- Public surface quick and detailed audit reports.
- Validation commands for Bash and PowerShell environments.

## Safety notes

- This repository helps structure safer coding-agent workflows.
- It is not a complete sandbox or security boundary.
- Users must still review commands, repository permissions, secrets, CI/CD configuration, and external network access.
- Do not use this template to bypass approvals, sandboxing, or review processes.

## Validation

- `bash tools/validate-spec.sh`
- `bash template/scripts/verify --strict-harness`
- `powershell -ExecutionPolicy Bypass -File tools/validate-spec.ps1`
- `powershell -ExecutionPolicy Bypass -File template/scripts/verify.ps1 -StrictHarness`

## Migration

No consumer-facing template behavior change is included in this OSS release readiness work.

Existing consumer repositories do not need to migrate solely because of this release readiness documentation.

## Manual release prerequisites

Before creating the GitHub release, maintainers must confirm:

- GitHub Secret scanning alerts.
- GitHub Actions logs do not expose secrets.
- Dependabot alerts.
- Repository About description and topics.
- Issues setting.
- Branch protection / ruleset.
- GitHub Private Vulnerability Reporting decision.
- Code scanning decision.
- LICENSE copyright holder.
- `template_version` update decision (current: not updated, because this PR only prepares OSS release documentation and audit artifacts; it does not change consumer-facing template behavior or contract).
- `MIGRATION.md` update decision (current: not updated, because this PR does not change consumer-facing template behavior or contract).
